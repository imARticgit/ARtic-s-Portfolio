Featured System Lift RNG

Lift RNG

A weighted randomization system that handles item rarity tiers (Common, Rare, Epic, Legendary). Uses math.random with weighted pools and fires RemoteEvents to update the client UI on roll results.

Featured System Steal a Food

Steal a Food

Commission game. Features a conveyor system where random foods spawn and move across a map line. Players can claim a plot, steal foods and redirect them to their collection area. Includes mutation variants such as Toxic and Angelic foods that change how the food looks.

Featured System Combat

Rough Combat System

A quick combat system I made. Features sprinting (LShift), an M1 combo, and a hitbox system. Used UserInputService for input, and RemoteEvents to damage dummies and play animations.

Watch it here ↗
Featured System PathFinding

Pathfinding Dummy

A pathfinding system using an R6 rig. Features a walking animation and a dash system for the player to escape. Uses PathfindingService to track the nearest player within 200 studs.
