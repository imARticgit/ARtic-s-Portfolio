System 04

Hologram

Advanced Hologram

Clones a live player's character, applies their real appearance via HumanoidDescription, then freezes every Motor6D into a fixed pose and reskins each part with ForceField material for that futuristic look. Since the rig is fully anchored, movement is driven by snapshotting each part's CFrame offset from the root and reapplying it every Heartbeat since true rigid-body motion with no physics joints. A token system per build slot prevents duplicate holograms if the server fires the spawn event twice.
